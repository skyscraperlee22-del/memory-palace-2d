# 记忆宫殿 1.0.1

- 系统应用名称由模板名称修正为「记忆宫殿」。
- 普通图标与圆形图标均更换为用户确认的拱门、台阶与书本图标。
- 移除模板的 3D 图标与 SDF 元数据及图片，避免 PICO 启动器继续显示旧图标。
- versionCode 升为 2；包名与签名保持一致，可覆盖安装升级。
- Debug / Release 构建通过，APK 中名称、图标像素、版本号及旧 3D 元数据移除均已核验，104 个网页运行资源与原版一致。
- PICO OS 6.1 模拟器已覆盖安装验证，桌面显示「记忆宫殿」及新拱门书本图标。
- 覆盖安装后，PICO 图标服务可能暂时显示旧图标；本次验证中等待其更新完成后自动显示新图，无需卸载或清除应用数据。

# 记忆宫殿 1.0

本次发布保留的 PICO 2D 窗口版本，提供楼层组织、分类物体库、物体摆放与旋转、知识笔记、带日期时间的待办，以及按楼层和分类颜色查看记录的 Memory overview。数据保存在本机。

同步提供可构建 Android 工程、已打包网页运行资源、原版 APK、应用图标、产品海报与实际窗口截图。

本版本未提供云同步、系统待办提醒或 Fullspace 漫游。
