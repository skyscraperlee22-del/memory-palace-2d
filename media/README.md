# 报名素材

- `icon.png`：1024 × 1024，直接复制自旧 APK 工程的实际启动图标。
- `icon.svg`：旧网页运行包原有的网页图标，与 Android 启动图标分开保留。
- `poster.png`：AI 生成的产品概念宣传海报，用于报名宣传，不是应用截图。
- `screenshot-pico-window.png`：PICO OS 模拟器中旧版真实 2D 窗口画面。

- `screenshot-demo-floor.png`：同一运行包在浏览器中的 8 物体示例场景。
- `screenshot-demo-overview.png`：当前楼层的 8 条示例记录看板。

浏览器示例截图来自 `docs/demo-state.json` 的明确标注合成内容，不是用户数据。
