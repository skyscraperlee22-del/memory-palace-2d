# Home Low-Poly Pack

This folder contains meter-scale GLB assets generated from the visual direction of
the supplied home-object reference sheet.

## Generate

```bash
pnpm assets:generate
```

## Conventions

- Coordinate system: glTF Y-up
- Units: meters
- Origin: bottom center
- Materials: opaque, low-metalness colors shared across the pack
- Runtime format: GLB

`manifest.json` lists the dimensions and filenames used by the runtime.
